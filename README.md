# Text-to-SQL AI

A Python-based GenAI project that converts natural-language questions into SQL queries using **Google Gemini** and executes them against a **SQLite** database.

## What it does

Instead of writing SQL manually, users can ask questions such as:

> Which customer has placed the most orders?

The application:

1. Reads the database schema
2. Sends the schema and question to Gemini
3. Generates a SQL query
4. Validates the generated query
5. Executes it against SQLite
6. Displays the result

Example:

```text
Question:
Which customer has placed the most orders?

Generated SQL:
SELECT T1.name
FROM customers AS T1
INNER JOIN orders AS T2
ON T1.id = T2.customer_id
GROUP BY T1.id
ORDER BY COUNT(T2.id) DESC
LIMIT 1;

Result:
Suresh
```

## Database

The sample SQLite database contains:

* `customers` — customer information
* `products` — product information
* `orders` — order information

The application reads the schema dynamically rather than hard-coding it into the main program.

## SQL Validation

Since the SQL is generated by an LLM, the application validates the query before execution.

Currently, only read-oriented `SELECT` queries are allowed, while operations such as `INSERT`, `UPDATE`, `DELETE`, `DROP`, and `ALTER` are rejected.

## Running the Project

Clone the repository and create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```powershell
venv\Scripts\activate
```

Install dependencies:

```powershell
pip install -r requirements.txt
```

Authenticate with Google Cloud:

```powershell
gcloud auth application-default login
```

Run the application from the project root:

```powershell
python -m app.main
```
